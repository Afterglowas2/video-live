# Оживи фото

Сайт: загружаешь фото, пишешь, что должно происходить, нейросеть (Runway) делает видео, и можно наложить свой звук.
Вторая вкладка: просто наложить звук на своё видео (без нейросети, ключ не нужен).

## Запуск

1. Нужен **ffmpeg** (`winget install ffmpeg` / `sudo apt install ffmpeg` / `brew install ffmpeg`).
2. `pip install -r requirements.txt`
3. Ключ Runway API: получи в [dev.runwayml.com](https://dev.runwayml.com) (генерация платная, по кредитам).
   Создай файл `.env` рядом с `app.py`:
   ```
   RUNWAYML_API_SECRET=твой_ключ
   ```
   Необязательно: `RUNWAY_MODEL=gen4_turbo` (модель) и `PORT=8000`.
4. `python app.py`, затем открой http://localhost:8000

## Структура

- `app.py`: сервер (Flask), задачи в фоне, склейка звука через ffmpeg.
- `static/index.html`: весь интерфейс одним файлом.
- `generate_video()` в `app.py`: единственное место, привязанное к Runway. Чтобы использовать другого провайдера (Luma, Kling, Replicate), замени только эту функцию.

## Важно

- Ключ API хранится только на сервере (`.env`), в браузер не попадает. `.env` не коммить в git.
- Задачи и файлы лежат в папке `jobs/` и не удаляются автоматически. Для публичного сайта добавь очистку по таймеру, лимиты и авторизацию, иначе чужие люди потратят твои кредиты.
- Загружай только свои фото и звук, на которые есть права. Не оживляй чужие лица без согласия человека.
- Для продакшена запускай через gunicorn: `gunicorn -w 1 --threads 8 -b 0.0.0.0:8000 app:app` (именно один процесс: задачи хранятся в памяти).
